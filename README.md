# 小組報告進度追蹤平台 (Team Report Progress Tracker)

專題核心流程可操作網站原型：**AI 專長適性分工 × 任務難度加權進度追蹤 × 透明化多維度貢獻看板**。

## ✨ 核心特色
1. **組員專長與偏好管理**：設定每位組員的核心專長標籤、喜好任務類型、希望避免項目與目標加權負載上限。
2. **不同難度權重的任務建立**：支援建立低難度 (`1x` / 10點)、中難度 (`2x` / 20點)、高難度 (`3x` / 30點) 任務與所需專長。
3. **AI 專長適性分工建議（雙引擎支援 + 可手動微調）**：
   - **內建多維度智慧配對引擎**：免設定 API Key 開箱即用，綜合計算專長契合度 (55%)、個人偏好 (20%) 與難度加權負載平衡 (25%)。
   - **Gemini API 串接模式**：可選填 Gemini API Key 切換真實大型語言模型即時生成建議。
   - **互動微調與負載模擬**：套用前可透過下拉選單手動調整負責人與協作夥伴，即時預覽調整後的各組員加權負載長條圖。
4. **任務狀態、截止日與多維度貢獻透明看板（拒絕只看完成件數）**：
   - 支援拉動進度滑桿 (`0% - 100%`)、切換任務狀態與截止日預警（準時、即將到期、逾期風險）。
   - 並排對比「傳統已完成件數」與「**已推進加權貢獻點數**（$\sum \text{難度點數} \times \text{進度\%} + \text{協作支援點數}$）」，公平呈現高難度任務執行者的真實投入。

## 🚀 啟動方式

需要 Python 3.8+（無須額外安裝第三方套件）：

```bash
python server.py
```

啟動後可透過瀏覽器開啟：
- 本機網址：`http://localhost:8088/?token=team2026`
- 預設存取通行碼：`team2026`
